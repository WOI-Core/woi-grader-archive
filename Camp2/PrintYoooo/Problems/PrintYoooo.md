
# PrintYoooo

ณ ดินแดนอัลกอริทึมอันไกลโพ้น มีตำนานเล่าขานถึงจอมเวทย์ผู้สามารถร่ายมนต์ "Yoooo" ได้ในพริบตา ว่ากันว่าความเร็วในการร่ายมนต์ของเขานั้นเหนือกว่าผู้ใด แต่จอมเวทย์ผู้นี้มีข้อแม้ว่า เขาจะไม่ปริปากบอกเคล็ดลับการร่ายมนต์นี้แก่ผู้ใดโดยตรง ท่านจะต้องค้นหาความลับนี้ด้วยตนเอง

**โจทย์**

จงเขียนโปรแกรมที่พิมพ์คำว่า "Yoooo" ออกมา

**Input**

ไม่มี Input

**Output**

พิมพ์คำว่า "Yoooo"
