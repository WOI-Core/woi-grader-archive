
# CombinatorialKingdom

ณ ดินแดนอันห่างไกล มีอาณาจักรที่ปกครองด้วยกฎแห่งการจัดเรียงและเลือกสรร กษัตริย์ทรงพระปรีชาสามารถต้องการทราบจำนวนวิธีในการเลือกอัศวิน k คนจากกองทัพ n คน เพื่อไปทำภารกิจสำคัญ แต่พระองค์ไม่ต้องการเสียเวลาในการคำนวณด้วยตนเอง พระองค์จึงมอบหมายให้เหล่าโปรแกรมเมอร์ช่วยคำนวณหาจำนวนวิธีดังกล่าว

**Input**

บรรทัดแรก ประกอบด้วยจำนวนเต็มสองจำนวน n และ k (0 <= k <= n <= 15) คั่นด้วยช่องว่าง

**Output**

บรรทัดเดียว แสดงจำนวนวิธีในการเลือก k สิ่งของจาก n สิ่งของ

**ตัวอย่าง**

<table>
<tr><th>Input</th><th>Output</th></tr>
<tr><td>5 2</td><td>10</td></tr>
<tr><td>10 3</td><td>120</td></tr>
</table>
