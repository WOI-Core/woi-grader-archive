
# Yoooo Infinite

ณ ดินแดนแห่งเสียงสะท้อนก้องกังวาน เหล่านักเดินทางต้องเผชิญหน้ากับบททดสอบแห่งความสุขนิรันดร์ พวกเขาต้องเปล่งเสียง "yoooo" ออกไปเรื่อยๆ จนกว่าจิตใจจะเบิกบานอย่างแท้จริง แต่ทว่า... ไม่มีใครรู้ว่าต้องเปล่งเสียงกี่ครั้งกันแน่!

**ภารกิจ:**

จงเขียนโปรแกรมที่รับจำนวนเต็ม N (1 <= N <= 10) เป็นจำนวนครั้งขั้นต่ำที่ต้องเปล่งเสียง "yoooo" และทำการพิมพ์ "yoooo" ออกมา N ครั้ง โดยที่จำนวนครั้งในการเปล่งเสียง "yoooo" ในแต่ละ test case อาจไม่เท่ากัน

**Input:**

บรรทัดแรกประกอบด้วยจำนวนเต็ม N (1 <= N <= 10) แทนจำนวนครั้งขั้นต่ำที่ต้องเปล่งเสียง "yoooo"

**Output:**

พิมพ์ "yoooo" ออกมา N บรรทัด แต่ละบรรทัดมีคำว่า "yoooo"

**ตัวอย่าง:**

  </tr>
</table>
