
# Secret Number

ณ หมู่บ้านเล็กๆ ที่ซ่อนตัวอยู่ในหุบเขา มีตำนานเล่าขานถึงตัวเลขลับ (Secret Number) ที่ถูกซ่อนไว้ในแต่ละบ้าน ตัวเลขนี้มีความพิเศษคือ มันสามารถบอกจำนวนตัวหารที่เป็นไปได้จากเลข 1 ถึง N ได้ ว่ามีทั้งหมดกี่ตัว! ชาวบ้านเชื่อว่าใครที่สามารถค้นหาจำนวนตัวหารของตัวเลขลับนี้ได้ จะได้รับพรจากเทพเจ้าแห่งคณิตศาสตร์

**Input**

บรรทัดแรกประกอบด้วยจำนวนเต็มสองจำนวน N และ Secret คั่นด้วยช่องว่าง

**Output**

พิมพ์จำนวนเต็มที่แสดงจำนวนตัวหารของ Secret ตั้งแต่ 1 ถึง N
