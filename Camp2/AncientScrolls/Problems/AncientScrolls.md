
# Ancient Scrolls

ณ หอสมุดโบราณแห่งอเล็กซานเดรียอันเก่าแก่ นักบวชหนุ่มนามว่า "ธีโอ" ได้รับมอบหมายให้ดูแลม้วนคัมภีร์โบราณจำนวนมาก แต่มีเพียงบางส่วนเท่านั้นที่มีข้อมูลสำคัญที่จำเป็นต่อการปกป้องโลกจากความมืดมิดที่กำลังจะมาเยือน ธีโอมีเวลาจำกัดและต้องการเลือกม้วนคัมภีร์ที่มีพลังเวทมนตร์รวมกันมากที่สุดเพื่อใช้ในการทำพิธีศักดิ์สิทธิ์ เขาจึงต้องการความช่วยเหลือจากคุณในการคำนวณหาผลรวมของพลังเวทมนตร์จากม้วนคัมภีร์ที่เขาเลือก

**อินพุต**

บรรทัดแรกประกอบด้วยจำนวนเต็มสองจำนวน `n` (1 <= n <= 100) แทนจำนวนม้วนคัมภีร์ทั้งหมด และ `k` (1 <= k <= n) แทนจำนวนม้วนคัมภีร์ที่ธีโอสามารถเลือกได้
บรรทัดที่สองประกอบด้วยจำนวนเต็ม `n` จำนวน แต่ละจำนวนแทนค่าพลังเวทมนตร์ของม้วนคัมภีร์แต่ละม้วน (1 <= magic <= 1000)

**เอาต์พุต**

ผลรวมของพลังเวทมนตร์ที่น้อยที่สุดจากม้วนคัมภีร์ที่ธีโอเลือก
