
# Mystic Crystals

ในดินแดนที่เต็มไปด้วยเวทมนตร์ มีหมู่บ้านเล็กๆ ที่ซ่อนตัวอยู่ในหุบเขา หมู่บ้านนี้เป็นที่รู้จักกันดีในเรื่องของคริสตัลลึกลับ ที่มีพลังงานเวทย์มนตร์ซ่อนอยู่ แต่ละคริสตัลมีพลังงานที่แตกต่างกันไป ชาวบ้านเชื่อว่าพลังงานรวมของคริสตัลทั้งหมดในหมู่บ้าน จะนำความสงบสุขและความเจริญรุ่งเรืองมาให้

กาลครั้งหนึ่ง มีนักเดินทางผ่านมายังหมู่บ้านแห่งนี้ เขาต้องการที่จะทดสอบความเชื่อของชาวบ้าน โดยการคำนวณพลังงานรวมของคริสตัลทั้งหมด เขาจึงขอให้ชาวบ้านแสดงคริสตัลทั้งหมดที่มีอยู่ และบันทึกค่าพลังงานของแต่ละคริสตัลไว้

จงเขียนโปรแกรมเพื่อช่วยนักเดินทางคำนวณหาพลังงานรวมของคริสตัลทั้งหมดในหมู่บ้าน

**Input**

บรรทัดแรก: จำนวนเต็ม `n` (1 <= n <= 10) แทนจำนวนคริสตัลในหมู่บ้าน
บรรทัดที่สอง: ตัวเลข `n` จำนวนเต็ม คั่นด้วยช่องว่าง แต่ละจำนวนแทนค่าพลังงานของคริสตัลแต่ละก้อน (1 <= energy <= 100)

**Output**

บรรทัดเดียว: พลังงานรวมของคริสตัลทั้งหมด
