
# PrabNumbers

ณ ดินแดนแห่งตัวเลข Prab มีความเชื่อว่าตัวเลขที่ถูกเลือกอย่างถูกต้องจะนำมาซึ่งความสงบสุข แต่มีเพียงผู้ที่มีญาณวิเศษเท่านั้นที่จะเลือกตัวเลขเหล่านั้นได้ กษัตริย์ Prab จึงได้จัดการแข่งขันเพื่อค้นหาผู้มีญาณวิเศษ โดยจะให้ผู้เข้าแข่งขันเลือกตัวเลขที่ K ที่มีค่าน้อยที่สุดจากชุดตัวเลขที่กำหนดให้

**Input**

บรรทัดแรกประกอบด้วยจำนวนเต็มสองจำนวน N และ K (1 <= K <= N <= 10) ซึ่ง N คือจำนวนของตัวเลขในชุด และ K คือตำแหน่งของตัวเลขที่ต้องการหา
บรรทัดที่สองประกอบด้วยตัวเลข N จำนวน ซึ่งแต่ละตัวเลขมีค่าไม่เกิน 100

**Output**

พิมพ์ตัวเลขที่ K ที่มีค่าน้อยที่สุด

**ตัวอย่าง**

<table>
    <tr>
        <td>Input</td>
        <td>Output</td>
    </tr>
    <tr>
        <td>5 3<br>5 2 8 1 9</td>
        <td>5</td>
    </tr>
    <tr>
        <td>4 1<br>7 3 9 1</td>
        <td>1</td>
    </tr>
</table>
