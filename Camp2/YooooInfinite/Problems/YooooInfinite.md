

# YooooInfinite

ณ ดินแดนแห่งความสุขนิรันดร์ มีเพียงคำว่า "yooo" เท่านั้นที่สามารถเติมเต็มจิตใจของผู้คนให้เบิกบานได้ แต่ความสุขนั้นก็เปราะบาง หาก "yooo" ถูกกล่าวซ้ำมากเกินไป ความเบิกบานก็จะจางหายไป

จงเขียนโปรแกรมเพื่อพิมพ์คำว่า "yooo" ออกมาตามจำนวนครั้งที่ได้รับ เพื่อรักษาความสุขของดินแดนแห่งนี้ไว้ โดยที่จำนวนครั้งของการพิมพ์ "yooo" ในแต่ละ submission นั้นจะไม่เท่ากัน

**Input**

บรรทัดแรกและบรรทัดเดียว ประกอบด้วยจำนวนเต็ม *n* (1 ≤ *n* ≤ 10) แทนจำนวนครั้งที่ต้องพิมพ์ "yooo"

**Output**

พิมพ์คำว่า "yooo" ออกมา *n* บรรทัด
