
# ShortestPathSum

ณ ดินแดนแห่งหนึ่งที่การเดินทางเชื่อมต่อกันด้วยเส้นทางเวทมนตร์ แต่ละเมืองมีค่าความสุขที่แตกต่างกัน อัศวินผู้กล้าได้รับมอบหมายภารกิจให้เดินทางจากเมืองเริ่มต้นไปยังเมืองที่ใกล้ที่สุด โดยมีเงื่อนไขว่าเขาต้องหาผลรวมของค่าความสุขของเมืองทั้งหมดที่สามารถเดินทางไปได้ด้วยเส้นทางที่สั้นที่สุด

**ข้อมูลนำเข้า**

บรรทัดแรกประกอบด้วยจำนวนเต็ม `n` (1 ≤ n ≤ 20), `m` (n-1 ≤ m ≤ n*(n-1)/2), และ `start_node` (1 ≤ start_node ≤ n) ซึ่งแสดงถึงจำนวนเมือง จำนวนเส้นทาง และเมืองเริ่มต้น ตามลำดับ
บรรทัดที่สองประกอบด้วยค่าความสุขของแต่ละเมือง `node_value` (1 ≤ node_value ≤ 10)
จากนั้นอีก `m` บรรทัด แต่ละบรรทัดมีจำนวนเต็ม `u`, `v`, และ `w` (1 ≤ u, v ≤ n, 1 ≤ w ≤ 10) แสดงว่ามีเส้นทางระหว่างเมือง `u` และ `v` ที่มีระยะทาง `w`

**ข้อมูลส่งออก**

ผลรวมของค่าความสุขของเมืองทั้งหมดที่สามารถเดินทางไปได้ด้วยเส้นทางที่สั้นที่สุด
